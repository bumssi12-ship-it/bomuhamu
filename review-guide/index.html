App Review Guide

Bomuhamu / BomBom Threads Manager

Last updated: 2026-10-11

threads_keyword_search

  1. Authorize the test account through Threads OAuth.
  2. Open Candidate Discovery and run Search now.
  3. Review public hamster-related results returned for explicit Japanese, Korean, or English hamster keywords.
  4. Open a returned public post/profile from the application.
  5. Observe that Like and Follow are not executed by the application; the user performs those actions in Threads and records completion locally.

threads_profile_discovery

  1. Enter an exact public Threads username in Direct Account Registration.
  2. Run Profile Lookup to retrieve the public profile.
  3. Import recent public profile posts for candidate review and hamster relevance scoring.
  4. Observe that the local relationship queue stores only workflow fields needed for review and tracking.

Safety controls

  • SAFE MODE is the default.
  • Scheduled collection never performs Like, Follow, Repost, or Reply.
  • Reply requires an explicit user action and is protected by cooldown/duplicate/daily-limit checks.
  • Access tokens and the App Secret are not shown on public pages or review reports.
