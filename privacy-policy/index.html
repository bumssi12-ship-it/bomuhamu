Privacy Policy

Bomuhamu / BomBom Threads Manager

Last updated: 2026-09-28

1. Purpose

Bomuhamu is a personal social-media management application that helps an authorized Threads user discover public hamster-related conversations, review public profiles, maintain local relationship notes and queues, prepare greeting text, and use approved Meta integrations.

2. Information processed

The application may process the authenticated Threads account identifier and profile, public Threads posts returned by approved discovery endpoints, public profile information requested by exact username, OAuth permission status, and local workflow records such as candidate scores, relationship states, user-confirmed Like/Follow records, reply history, and application settings.

3. Use of information

Information is used only to provide requested application functionality, authenticate approved API requests, display public discovery results, prevent duplicate or excessive actions, maintain the user's local workflow state, and diagnose permission or API status.

4. Storage and security

The personal-use deployment primarily stores operational state locally on the user's own computer in SQLite and configuration files. Access tokens are used for authenticated API access and must not be published. The application does not intentionally expose the Threads App Secret in its user interface or review reports.

5. Sharing and sale

Bomuhamu does not sell personal information and does not intentionally provide personal information to advertisers. Data is shared with third-party services only as necessary to perform actions explicitly requested by the user or as required by law.

6. User control

Like and Follow are performed by the user in Threads. Public discovery and profile lookup depend on permissions granted through Meta. API replies are initiated only by an explicit user action in the application and are subject to local duplicate and daily-limit checks.

7. Deletion

The user can revoke the application's Meta permissions and delete locally stored application data. See the User Data Deletion page.

8. Third-party services

Meta, Instagram, Threads, GitHub, and other third-party services used with the application are governed by their own terms and privacy policies.

9. Contact

For privacy or deletion questions, use the developer contact registered for the Bomuhamu Meta application.
