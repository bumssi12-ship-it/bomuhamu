Privacy Policy

Bomuhamu / BomBom Threads Manager

Last updated: 2026-10-11

1. Purpose

Bomuhamu is a personal social-media management application that helps an authorized Threads user discover public hamster-related conversations, review public profiles, maintain local relationship notes and queues, prepare greeting text, and use approved Meta integrations.

2. Information processed

The application may process the authenticated Threads account identifier and public profile, public Threads posts returned by approved discovery endpoints, public profile information requested by exact username, OAuth permission status, and local workflow records such as candidate scores, relationship states, user-confirmed Like/Follow records, reply history, and application settings.

3. Data minimization and use

Only information needed for the requested workflow is processed. It is used to authenticate approved API requests, display public discovery results, score and de-duplicate candidates, prevent duplicate or excessive actions, maintain local workflow state, and diagnose permission or API status.

4. Storage and security

The personal-use deployment primarily stores operational state locally on the user's own computer in SQLite and configuration files. Authentication tokens are kept in local configuration and are not intentionally included in reports, exports, logs, or public pages. The Threads App Secret is not displayed by the application.

5. Retention

Local workflow data is retained until the user deletes it or removes the application data. The user may export selected relationship/candidate records before deletion. Public content may change or disappear on Threads independently of any locally cached workflow metadata.

6. Sharing and sale

Bomuhamu does not sell personal information and does not provide personal information to advertisers. Data is transmitted to Meta only as needed for API requests explicitly supported by the connected Threads application, or as required by law.

7. User control

Like and Follow are performed by the user in Threads. Public discovery and profile lookup depend on permissions granted through Meta. API replies are initiated only by an explicit user action in the application and are subject to local duplicate, cooldown, and daily-limit checks.

8. Deletion and revocation

The user can revoke the application's Meta permissions and delete locally stored application data. See the User Data Deletion page.

9. Third-party services

Meta, Instagram, Threads, GitHub, and other third-party services used with the application are governed by their own terms and privacy policies.

10. Contact

For privacy or deletion questions, use the developer contact registered for the Bomuhamu Meta application.
