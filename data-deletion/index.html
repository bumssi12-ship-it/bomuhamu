User Data Deletion

Bomuhamu / BomBom Threads Manager

Last updated: 2026-10-11

How to remove application-controlled data

  1. Revoke Bomuhamu's access in the relevant Meta/Threads account settings if future API access is no longer desired.
  2. Stop Bomuhamu on the user's computer.
  3. Delete the local application database and other local workflow files from the Bomuhamu installation when local records should be removed.
  4. Remove locally stored authentication-token configuration if the application will no longer be used.
  5. If assistance is required, contact the developer address registered for the Bomuhamu Meta application and request deletion instructions.

Data covered

Locally controlled data may include candidate records, public profile/post metadata cached for review, relationship states, action history, greeting text/history, runtime status, configuration, and locally stored authentication tokens.

What deletion does not do

Deleting Bomuhamu's local data does not delete content or account data hosted by Meta. Revoking Bomuhamu's permissions prevents future authorized API access. Content controlled directly by Meta remains subject to Meta's own account and deletion controls.

Confirmation

For this personal-use deployment, local deletion is under the account owner's direct control. The application does not maintain a separate hosted user database.
