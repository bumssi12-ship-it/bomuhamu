User Data Deletion

Bomuhamu / BomBom Threads Manager

Last updated: 2026-09-28

How to remove application-controlled data

  1. Revoke Bomuhamu's access from the relevant Meta/Threads account settings if future API access is no longer desired.
  2. Stop Bomuhamu on the user's computer.
  3. Delete the local SQLite database and local configuration/token files from the Bomuhamu installation if local workflow data should be removed.
  4. If assistance is required, contact the developer address registered for the Bomuhamu Meta application and request deletion instructions.

Data covered

Locally controlled data may include candidate records, public profile/post metadata cached for review, relationship states, action history, greeting text/history, configuration, and locally stored authentication tokens.

Meta-hosted data

Content and account data controlled directly by Meta are subject to Meta's own account, privacy, and deletion controls. Revoking Bomuhamu's permission prevents future authorized API access but does not independently delete data hosted by Meta.
