Bomuhamu / BomBom Threads Manager

Official policy and review-support pages for a personal Threads community-management application operated by the authenticated account owner.

Application purpose

The application helps the user discover public hamster-related Threads posts, review public profiles, organize a local relationship queue, prepare language-appropriate greeting text, and record user-confirmed relationship actions.

Public discovery uses approved Threads API capabilities. Like and Follow are not automated. Any API Reply requires an explicit action by the authenticated user in the application.

Permissions requested for public discovery

  • threads_keyword_search — discover public hamster-related posts using explicit keywords selected by the user.
  • threads_profile_discovery — retrieve a public profile and recent public posts for an exact username selected by the user.

The application does not use these permissions for private-profile access, follower scraping, bulk following, or autonomous engagement.

Automation boundaries

  • Candidate collection, scoring, deduplication, queue prioritization, and local analytics can be automated.
  • Like and Follow remain user-controlled actions in Threads.
  • Reply actions are not scheduled and require an explicit user click.
  • Local cooldowns, duplicate checks, daily limits, and a do-not-contact flag are applied to the workflow.
