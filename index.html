Bomuhamu / BomBom Threads Manager

Official policy and review-support pages for the personal Threads community management application used by the authenticated account owner.

Application purpose

The application helps the user discover public hamster-related Threads posts, review public profiles, organize a local relationship queue, prepare language-appropriate greeting text, and record user-confirmed relationship actions.

Public discovery uses approved Threads API capabilities. Like and Follow are not automated. A reply is sent only when the authenticated user explicitly chooses the reply action in the application.
